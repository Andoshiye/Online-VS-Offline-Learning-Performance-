# Online vs Offline Learning Performance Analysis

## Project Overview

This project compares student performance in online and offline learning environments to understand which method leads to better academic outcomes based on exam scores, focus level, retention, and study hours.

## Tools Used

Excel
Pivot Tables
Basic Statistical Functions
Data Visualization

## Dataset Overview

The dataset includes student information across different subjects and learning modes with the following key variables
Study Hours
Focus Level
Retention Score
Exam Score
Subject
Learning Mode

## Methodology

Data cleaning and preparation
Exploratory data analysis using pivot tables
Comparison of averages across learning modes
Correlation analysis between key variables
Visual dashboard creation

## Key Insights

Offline learners showed slightly higher average exam performance compared to online learners
Retention and focus levels were also slightly higher in offline learning
Study hours showed very weak correlation with both focus and retention, suggesting other factors play a stronger role in performance

## Subject Performance Insight

English and History showed better average exam scores in online learning compared to offline learning
Mathematics, Programming, and Science performed better in offline learning compared to online learning
This suggests that the effectiveness of learning mode may depend on the subject area

## Conclusion

Offline learning shows slightly better overall performance in this dataset, but subject differences indicate that no single learning mode is universally better for all disciplines
